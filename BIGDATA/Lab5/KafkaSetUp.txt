///////////////////////// Kafka Initial setup///////////////////////////////////////////////
1->  In server.properties file, change log.dirs path
#log.dirs=/tmp/kraft-combined-logs (change this path)
log.dirs=D:/ApacheKafka/kafka/logs

2-> Create logs folder in kafka installation folder( only if logs folder not available)
D:\ApacheKafka\kafka\logs

3-> Write this command in server.properties (set controller.quorum.voters)
controller.quorum.voters=1@localhost:9093

(Note: 1 = node.id and localhost:9093 = controller listener port)

4-> run this command to generate random UUID
.\bin\windows\kafka-storage.bat random-uuid

5-> run formate command
.\bin\windows\kafka-storage.bat format -t <UUID> -c .\config\server.properties --ignore-formatted
.\bin\windows\kafka-storage.bat format -t Vk1MqZqsTOyZTLrR5UNA0w -c .\config\server.properties --ignore-formatted

6-> run this command to Start Kafka Server in KRaft mode
.\bin\windows\kafka-server-start.bat .\config\server.properties

///////////////////// Create topic, producer and consumer////////////////////////////////////////

7-> Create Kafka topic
.\bin\windows\kafka-topics.bat --create --topic my-topic --bootstrap-server localhost:9092

8-> Create Producer(open new cmd for it)
.\bin\windows\kafka-console-producer.bat --topic my-topic --bootstrap-server localhost:9092


9-> Create consumer(open new cmd for it)
.\bin\windows\kafka-console-consumer.bat --topic my-topic --from-beginning --bootstrap-server localhost:9092


////////////Advance Kafka topic management commands in KRaft mode////////////////////////////////////
10-> Create a kafka topic with some advance configurations
.\bin\windows\kafka-topics.bat --create --topic my-topic --partitions 1 --replication-factor 1 --bootstrap-server localhost:9092

(//explainations
--partitions = Number of partitions (logical shards), usually between 1-3
--replication-factor = 1 (Keep 1 in KRaft single-node mode))



11-> Describe a topic
.\bin\windows\kafka-topics.bat --describe --topic my-topic --bootstrap-server localhost:9092

12->To see available List Topics
.\bin\windows\kafka-topics.bat --list --bootstrap-server localhost:9092

13-> Delete a topic
.\bin\windows\kafka-topics.bat --delete --topic my-topic --bootstrap-server localhost:9092

(to enable this command , add this code in server.properties
delete.topic.enable=true
)

14-> To increase topic partition(we can only increase the topic partition, can't decrease it)
.\bin\windows\kafka-topics.bat --alter --topic my-topic --partitions 3 --bootstrap-server localhost:9092



//////////////////// Komendy faktycznie wykonane na tym komputerze (Windows, C:\kafka4.4) ////////////////////

0-> Java 21 (C:\BigData\jdk21) musi byc widoczna dla Kafki (kafka 4.x wymaga Javy 17+).
    Na stale (zmienne uzytkownika; potem otworz NOWE okno cmd):
    setx JAVA_HOME "C:\BigData\jdk21"
    (oraz dopisac C:\BigData\jdk21\bin do PATH)
    Tylko na biezace okno cmd:
    set JAVA_HOME=C:\BigData\jdk21
    set PATH=%JAVA_HOME%\bin;%PATH%

    Konfiguracja C:\kafka4.4\config\server.properties (juz poprawna, bez zmian):
    log.dirs=C:/kafka4.4/logs
    controller.quorum.voters=1@localhost:9093

4-> cd C:\kafka4.4
    .\bin\windows\kafka-storage.bat random-uuid
    wynik: Vk1MqZqsTOyZTLrR5UNA0w
    (linia "main ERROR Reconfiguration failed..." to zwykly komunikat log4j, mozna ja zignorowac)

5-> .\bin\windows\kafka-storage.bat format -t Vk1MqZqsTOyZTLrR5UNA0w -c .\config\server.properties --ignore-formatted

6-> set KAFKA_HEAP_OPTS=-Xmx1G -Xms1G
    .\bin\windows\kafka-server-start.bat .\config\server.properties
    (okno z serwerem ma zostac otwarte; w logu: "Kafka Server started", port 9092)

7-> .\bin\windows\kafka-topics.bat --create --topic my-topic --bootstrap-server localhost:9092
    wynik: Created topic my-topic.

8-> producent (w tescie wyslane 3 wiadomosci przez stdin; normalnie w osobnym cmd, wpisujesz tekst + Enter):
    .\bin\windows\kafka-console-producer.bat --topic my-topic --bootstrap-server localhost:9092
    wyslane: hello kafka / druga wiadomosc / trzecia wiadomosc

9-> konsument (osobne cmd; w tescie z limitem 3 wiadomosci):
    .\bin\windows\kafka-console-consumer.bat --topic my-topic --from-beginning --bootstrap-server localhost:9092
    wersja z limitem: dopisac --max-messages 3 --timeout-ms 15000
    wynik: odebrane wszystkie 3 wiadomosci, "Processed a total of 3 messages"

11-> .\bin\windows\kafka-topics.bat --describe --topic my-topic --bootstrap-server localhost:9092
    wynik: PartitionCount: 1, ReplicationFactor: 1, Leader: 1

14-> .\bin\windows\kafka-topics.bat --alter --topic my-topic --partitions 3 --bootstrap-server localhost:9092
    potem ponownie describe: PartitionCount: 3 (partycje 0, 1, 2, Leader: 1)

12-> .\bin\windows\kafka-topics.bat --list --bootstrap-server localhost:9092
    wynik: __consumer_offsets, my-topic

Pominiete: krok 10 (temat my-topic juz istnial, wiec drugie --create by sie nie udalo)
           krok 13 (--delete) - nie wykonywany, zeby zostawic temat do dalszych cwiczen.
